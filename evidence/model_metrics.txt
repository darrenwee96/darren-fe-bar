Holiday alignment checks
- Event alignment now uses daily-offset overlap, not exact week offset. For a shifted weekday holiday, each target-week day maps to the prior event occurrence with the same days-to-event offset and blends the matched prior weeks by day count. The blend does not renormalize if a matched prior-year week is NULL, which is intentionally conservative and can depress some ratios, e.g. SKU-MC03 event-naive ratio 0.404.
